# Power BI 施工包

本目录用于在 Windows Power BI Desktop 中复刻项目看板。项目不提供伪造的 `.pbix`；按本说明构建后，请自行保存正式 PBIX。数据是 2026 年 7 月单月、账号粒度的深度脱敏样本，不能解释趋势或因果。

## 1. 导入与模型

1. 打开 Power BI Desktop，进入“转换数据 → 管理参数”，新建文本参数 `pDataPath`。
2. 参数值指向仓库内 `data/processed/account_segments.csv` 的绝对路径。
3. 新建空白查询，在高级编辑器中依次使用 [power_query.m](power_query.m) 的四段代码，查询名必须分别为 `账户投放`、`品牌`、`账号`、`日期`。
4. 在 `账户投放` 中，仅保留公开匿名字段。不要改用包含客户字段的基础 CSV。
5. 建立关系：`品牌[品牌]` 1:* `账户投放[brand_name]`；`账号[account_id]` 1:* `账户投放[account_id]`；`日期[日期]` 1:* `账户投放[month_date]`。筛选方向均为维表到事实表。
6. 把 `日期` 标记为日期表。由于只有一个自然月，日期维度只为模型规范，不制作趋势图。

## 2. 度量值与主题

1. 在模型中新增空表“指标”，逐段复制 [measures.dax](measures.dax) 的度量值。
2. 将百分比设置为：CTR、播放率保留 2 位百分比；ROI 保留 2 位小数；覆盖率与占比保留 1 位百分比。
3. 将金额/成本设置为小数 2 位、千位分隔；展示/点击/播放/账号数为整数。
4. 通过“视图 → 主题 → 浏览主题”导入 [theme.json](theme.json)。若本机没有微软雅黑，替换为思源黑体或等宽可读的中文无衬线字体。

## 3. 三页布局与字段映射

### 第 1 页：经营总览

- 顶部切片器：`品牌[品牌]`、`账户投放[action_segment]`、`账户投放[is_eligible]`。
- KPI 卡：`总消耗`、`24H混合ROI`、`加权CTR`、`加权播放率`、`有效账号数`。
- Pareto 组合图：X 轴 `account_id`（按 `总消耗` 降序），柱 `总消耗`，折线 `累计消耗占比`；增加 80% 常量线。
- 洞察卡：显示 `高消耗边界`、`有效样本消耗覆盖率`，并放置一张文本卡说明单月与脱敏边界。

### 第 2 页：品牌对标

- 散点图：X=`总消耗`，Y=`24H混合ROI`，大小=`账号数`，图例=`brand_name`；添加 ROI=1 参考线。
- 条形图：轴=`brand_name`，值=`总消耗`，按值降序。
- 矩阵：行=`brand_name`；值=`总消耗`、`24H混合ROI`、`加权CTR`、`加权CPC`、`加权播放率`、`重算播放成本`。
- 条件格式只用于相对提示，不把 ROI=1 解释为公司盈利。

### 第 3 页：账号行动池

- 横向条形图：轴=`action_segment`，值=`账号数`。
- 明细表：`account_id`、`account_name`、`brand_name`、`platform_spend`、`mixed_roi_recalc`、`ctr_recalc`、`play_rate_recalc`、`play_cost_recalc`、`action_segment`。
- 表格按 `platform_spend` 降序；为消耗与 ROI 设置数据条/色阶；保留搜索型切片器。
- 在页面说明中写出规则：消耗门槛 50、有效账号 P75=735.80、ROI 参考线 1.0。

## 4. 口径与审计重点

- 品牌与全局比率必须“先汇总基础量，再相除”，不能 `AVERAGE` 账号 CTR/ROI。
- 源字段 `play_cost` 实际与 `plays / platform_spend` 一致，方向与常规“成本”相反。所有页面必须使用 `重算播放成本 = 总消耗 / 总播放` 或 `play_cost_recalc`。
- 过滤后 `高消耗边界` 度量会随上下文变化；用于复刻本项目固定行动标签时，以导入的 `action_segment` 为准。
- 绝对金额经过同比例缩放，只用于该数据集内部比较。

## 5. 对账基线

无筛选状态应得到：551 个账号、8 个品牌、总消耗 207,057.29、24H 混合 ROI 1.03、有效账号 283、有效样本消耗覆盖率 99.43%、固定高消耗边界 735.80。五类行动池合计必须等于 551。

完成后按 [dashboard_build_checklist.md](dashboard_build_checklist.md) 逐项勾选，再保存 `.pbix`。
